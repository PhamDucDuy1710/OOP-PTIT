# CodePTIT - OOP Java

Repository tổng hợp các bài tập môn **Lập trình hướng đối tượng (OOP)** bằng **Java** mình đã thực hiện trên nền tảng **CodePTIT** trong quá trình học tập và rèn luyện. 

Các bài tập được phân loại theo từng chủ đề nhằm giúp việc theo dõi, quản lý mã nguồn và ôn tập trở nên dễ dàng hơn.

---

### 📚 Các chủ đề

- Khai báo lớp và đối tượng
- Lập trình Java cơ bản
- Mảng
- Mảng đối tượng
- Quan hệ giữa các lớp
- Ứng dụng Java Collection
- Vào ra file
- Xâu ký tự

---

### 🎯 Mục đích

- Lưu trữ các bài tập OOP Java đã giải trên CodePTIT.
- Hệ thống hóa kiến thức theo từng chủ đề cụ thể.
- Luyện tập và củng cố kỹ năng lập trình hướng đối tượng với Java.
- Dễ dàng tra cứu và ôn tập lại các bài đã làm.
- Phục vụ mục đích học tập và luyện tập cá nhân.
